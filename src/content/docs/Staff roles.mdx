### Moderators

List of moderators: https://vocadb.net/User?groupId=Moderator

Responsibilities:

- Enforcing [[rules]]
- Enforcing [[discussion rules]]
- Promoting users to [[User groups#trusted-user|trusted users]]
- Promoting [[User groups#trusted-user|trusted users]] to [[User groups#moderator|moderators]]
- Simple wiki content updates/fixes
- Handling [[entry reports]]
- Handling [[Artist verification|artist verification requests]]
- Handling simple [[Content removal guidelines|content removal requests]]
- Handling user account deletion requests
- Maintaining tag mappings (Niconico tag -> VocaDB tag)
- Handling spammers (with [StopForumSpam](https://www.stopforumspam.com/))

### Trusted users

List of trusted users: https://vocadb.net/User?groupId=Trusted

Responsibilities (optional):

- Handling regular [[entry reports]]
- Participating in rule discussions
